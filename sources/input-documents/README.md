- DOCX a PDF původního návrhu `rigo` mají po normalizaci extrahovaného textu shodu přibližně 99,9 %; jde prakticky o dvě podoby stejného obsahu.
- Dokument „doporučená úprava 2023“ a starší výtah studijního řádu nejsou samy o sobě důkazem aktuálních pravidel pro rok 2026. Rozhodující je současný předpis a potvrzení LF OU.
