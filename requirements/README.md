# Požadavky

Tato složka obsahuje pouze anonymizované požadavky důležité pro plánování, rukopis a export.

- [`institutional.md`](institutional.md) – pracovní souhrn pravidel instituce a nevyřešené brány
- [`export-profile.md`](export-profile.md) – mapování požadavků na budoucí DOCX/PDF export

Časově proměnlivé údaje musí mít datum posledního ověření a odkaz na autoritativní zdroj. Individuální rozhodnutí, kontakty a soukromá korespondence patří do `private/`.
